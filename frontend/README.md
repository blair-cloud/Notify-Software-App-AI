# Notify — Frontend Application

React 19 + TypeScript + Vite + Tailwind CSS application for Notify Commercial Real Estate Management.

## Structure
- `src/components/`: Reusable UI components (Navbar, Hero, Modals, Cards)
- `src/pages/`: Feature pages (Manage Units, Collect Rent, Stay Notified, Support, Pricing)
- `src/context/`: Context providers (LanguageContext)
- `src/data/`: Data models & localized translations
- `index.html`: Entry point HTML

## Scripts
- `npm run dev`: Start Vite development server on port 3000
- `npm run build`: Production build output to `dist/`
- `npm run lint`: Type-check React code
